# Video bundle router

This bundle groups the video/motion skill set under one always-loaded entry. Sub-skills below are **files inside this directory, not registered skills** — they are not loaded into context until you read them. Match the request to a row, read that `SKILL.md`, then follow it. Cross-references between sub-skills resolve to sibling directories inside this bundle.
